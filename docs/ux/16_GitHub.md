# GitHub

## Overview

The GitHub section displays GitHub repository information, pull requests, and integration details.

---

## User Flow

1. User navigates to GitHub section
2. User views connected repositories
3. User can view pull requests
4. User can view issues
5. User can view commits
6. User can sync with Genesis

---

## UI Components

### Repository Selector

- Repository list
- Search functionality
- Filter by organization
- Sync status indicator

### Repository Overview

- Repository name
- Description
- Stars count
- Forks count
- Watchers count
- Last updated
- Branch selector

### Pull Requests

- PR list
- PR status (open/merged/closed)
- PR author
- PR reviewers
- Merge status
- Last updated

### Issues

- Issue list
- Issue status (open/closed)
- Issue labels
- Assigned user
- Comment count
- Last updated

### Commits

- Commit list
- Commit message
- Commit author
- Commit timestamp
- Changed files count
- Additions/deletions

### Branches

- Branch list
- Branch status

- Last updated

### Sync Controls

- Last sync time
- Sync status
