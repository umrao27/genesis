# Overview

## Overview

The workspace overview page provides a comprehensive view of the workspace status, recent activity, and quick actions.

---

## User Flow

1. User lands on workspace
2. User sees overview dashboard
3. User can access quick actions
4. User can see recent projects
5. User can view team members

---

## UI Components

### Header Section

- Workspace name
- Workspace avatar
- Member count
- Last updated time

### Quick Stats

- Active projects count
- Team members count
- Recent documents count
- Tasks count

### Recent Activity

- Activity feed
- Timestamp
- User avatar
- Activity description

### Quick Actions

- Create new project
- Create new document
- Add team member
- Upload file

### Projects Section

- Project cards
- Project status
- Team members
- Last modified date

### Team Section

- Team member avatars
- Member roles
- Active status
- Invite button

### AI Suggestions

- Recommended next steps
- Suggested features
- Performance tips
