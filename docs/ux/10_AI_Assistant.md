# AI Assistant

## Overview

The AI Assistant helps users throughout the Genesis platform by answering questions and providing guidance.

---

## User Flow

1. User clicks AI Assistant icon
2. Chat panel opens
3. User types question
4. AI processes and responds
5. User can follow up
6. User can save conversation

---
