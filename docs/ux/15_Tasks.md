# Tasks

## Overview

The Tasks section helps manage project tasks, assignments, and progress tracking.

---

## User Flow

1. User navigates to Tasks
2. User views task list or board
3. User can create new task
4. User can assign task
5. User can update task status
6. User can add comments

---
