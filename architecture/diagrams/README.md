# Architecture Diagrams

This folder contains all architecture diagrams for the Genesis project.

## Diagram Types

- **Context Diagram**: Shows the system in the context of its environment
- **Container Diagram**: Shows the high-level technology choices and communication between containers
- **Deployment Diagram**: Shows how the system is deployed across infrastructure

## Tools

Diagrams are created using Draw.io format (.drawio) for easy collaboration and version control.
